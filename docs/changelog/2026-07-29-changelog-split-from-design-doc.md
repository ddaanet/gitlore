# 2026-07-29 — The changelog became its own file, and the design doc dropped the narrative it had been carrying

`docs/design.md` was doing two jobs at once: stating what the system is, and recording how each piece got there. The two answer different questions and decay differently — a mechanism description has to track the code, while a write-time record is correct forever precisely because it is dated. Fused, the narrative rots into a museum of retired designs that a reader has to date-check line by line, and the mechanism it surrounds gets read as history too. So the dated entries moved here, the four tables became prose subsections (a table forces every row to the width of the narrowest cell; the reasoning is the payload), and D12–D19's bodies were rewritten to state present-tense mechanism. Dates that *ground* a claim stayed with the claim — the 2026-06-10 channel characterization, the 2,441-transcript `Bash`-arm measurement, the 2026-07-17 reconcile numbers, the 76-bullet advisory gating — because deleting those turns evidence into assertion. Two rejected alternatives moved to the section that exists for them, leaving one-line pointers: the tf-idf hook scorer (refuted on this store's own corpus) and the `PreToolUse`-deny recall gate.

The fusion had also hidden two claims that were no longer true, which is the argument for the split rather than a side effect of it. D14 listed a branch-collision notice and a "branch synced with `live`" success message, both deleted by D17's branch model; `session-start.sh` emits neither. D17's lockstep paragraph still said tier divergence resolution was unautomated, a week after it shipped (2026-07-22). Both were verified against the code before rewriting. Three "later slice" comments in `scripts/cc-hooks/session-start.sh` had drifted the same way and now state current behaviour.
