# 2026-07-22 — Happy-path evals now cover the tier flow, active recall, and `/gitlore:add-tier`

The eval harness graded exactly one flow: `run-evals.sh` ran a fixed two-turn script and a fixed assertion chain inline. Three flows finished by D17 slice 3 and D18 have entirely different end states, so scenarios became pluggable — `assert` names a script in `tests/evals/asserts/`, `setup` names a fixture in `tests/evals/setups/`, `approval_message` is optional (a flow with no approval gate is one turn), and `{{EVAL_REPO}}` in a prompt expands at trial time so a scenario can name a URL the fixture just created. The eval repo's hooks are now **derived from the plugin's own `hooks/hooks.json`** rather than hand-listed: the hand-written subset was `PostToolUse` alone, which left every `PostToolBatch` registration — composition, the commit gate, recall, add-tier — dark in every eval ever run. Skills and commands are copied in too, so the prompt contracts the agent reads are the shipped ones. Two mechanism notes settled by probe: **all four hook events fire under `claude --print`** (`SessionStart`, `PreToolUse`, `PostToolUse`, `PostToolBatch` — previously only `PostToolUse` was known to), and `protocol.file.allow` cannot be set as repo config for a tier mount, because the transport policy is read by the *clone* `submodule add` spawns; `GIT_CONFIG_*` reaches it and survives the hooks' local-env-var unset. The recall assertion reads the **session transcript** (located by session id, not by deriving the projects-dir mangling of cwd) because every repo-visible signal is identical whether the body arrived by injection or by the agent simply Reading the file — and telling those apart is the entire point of the mechanism. Assertions are themselves tested in `lib/asserts.bats` against a good end state and against the breakage each exists to catch: an assertion that always passes turns its scenario into an expensive no-op and the run still looks green. All five scenarios pass live at `EVAL_K=1`; 483 unit + integration green. This run is also the first time `add-tier-batch.sh` ever fired — its `PostToolBatch` registration was frozen at session start in the session that built it.
