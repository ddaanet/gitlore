# 2026-07-31 — The `docs/` + `plans/` layout adopted: prospective content to a root `plans/`, the changelog split into an index and per-entry bodies

`docs/` was carrying two kinds of file with opposite lifecycles: the living design and its changelog, which state current truth, and eighteen plans plus five specs, which describe work not yet done or how something was built. A reader landing in `docs/` had to date-check each one to know which they were holding. The plans and specs are now `plans/` at the repo root, flat — `docs/superpowers/{plans,specs}/` went with them, since which skill generated a file is not a property worth encoding in a path. `docs/references/` stays where it is: reference material is current, so it belongs with the design.

`plans/` is a new top-level entry, and the gate declaration is an allow-list, so `tests/justfile_gates.bats` refused the tree until it was named. It joins `memory/` and `docs/` on the deliberate-exclusion list rather than in `precommit_inputs` — no check reads it, and a prose-only commit should leave a green gate green. Navigational cross-references between plans were rewritten to the new paths; two occurrences inside fenced blocks were not, because they quote artifacts as they stood (a `git add` from a completed step, and a `docs/plugin-readme.md` snippet), and a quoted artifact is not a link.

`docs/changelog.md` had become the shape the layout exists to avoid: one file holding all 61 bodies, growing without bound, where every append rewrites a file whose per-entry records are each supposed to be frozen. It is now an index of one-line pointers, newest first, beside `docs/changelog/YYYY-MM-DD-slug.md` bodies. The bodies were carried over **verbatim** and the split verified by reconstructing the pre-split file from the index links and diffing it against `HEAD` — byte-identical. Two conventions were settled against the reference implementation rather than by copying it. Six entries carry a bare `## YYYY-MM-DD` heading with no title; they kept it, and their index link shows the date alone, because inventing a title would author text into a dated record. And `claude-plugin-dev`'s own split (`c37f3cb`) reworded its bodies and gave them new headings — that part was not followed, for the reason the layout gives for splitting at all: a dated record is correct forever precisely because it is dated, so the only text authored here is the index hook.

The layout comes from `claude-plugin-dev` and is being propagated across every plugin repo in this family.
