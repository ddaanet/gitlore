# 2026-07-22 — Active recall (FR16/D18) — a memory body can now be fetched from a trigger the prompt never carried

CC's native recall classifies once, against the user prompt, and is told not to re-select within a conversation, so a fact keyed on something that surfaces mid-task had no route into context. `skills/recall/SKILL.md` has the agent write `.claude/gitlore-recall` (≤5 paths relative to the store, or `no match`); `scripts/cc-hooks/recall-batch.sh` on `PostToolBatch` resolves it and emits the bodies as `additionalContext`. Grepping the shipped binary settled the mechanism question first: no `injectToolCall`/`forceRead` field exists at any version, so a hook cannot make the agent Read — but it does not need to, since reading the files itself is one round trip instead of two and puts the selection in a file that can be validated. A `PreToolUse` deny gating the first durable write was designed and **rejected**: a denial as the normal path costs a turn every editing episode and devalues the stop channel, and arming it at `UserPromptSubmit` would have duplicated the native classifier firing at the same moment. Over the cap reads nothing rather than truncating — nine entries means no selection was made, and keeping the first five would conceal it. The ledger that stops double-fetching records `<hash> <relpath>` from every `Read` under the store, which captures native recall too ("Recalled 1 memory" is a real `Read` in `.tool_calls[]`), and is cleared at `SessionStart` **and `PreCompact`** — a compaction leaves a summary, not tool results, and only the project-root `CLAUDE.md` is guaranteed re-injected, so presence cannot be inferred across it. Alongside: always-on directives moved out of `memory/MEMORY.md` (20,381 → 18,676 bytes; one project-state line was 3.3KB, 18% of the whole index) into `CLAUDE.md` and a path-scoped `.claude/rules/shell.md`, whose `paths:` frontmatter fires on *reading* a matching file — the harness's own answer to the same mid-task-trigger problem. 28 new cases; 410 unit + integration green.
