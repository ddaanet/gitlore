# 2026-07-22 — One merge policy at every level — a diverged tier now resolves exactly like diverged memory

Every store has the same two gates: the pending commit against the store's own local `live` (`pre-commit`), and local `live` against the store's own remote (`pre-push`). Memory had both wired to `gitlore_yield_merge`; the tiers had both gates in the right places but *reported* at each — "resolving a tier divergence is not yet automated" — so the store simply stopped publishing while its message repeated every session. Both call sites now yield, and `/gitlore:resolve` walks every store rather than memory alone. Almost nothing had to be built: `gitlore_prepare_merge`, `gitlore_yield_merge` and `gitlore_write_merge_state` were already parameterized by store path, and `gitlore_merge_state_file` resolves `--git-path` *inside whichever store it is handed*, so each tier gets its own state file in its own gitdir with no collision. The single real blocker was the **continuation**: `load_continuation_state` derived its store from `gitlore_memory_path`, which would have committed in memory while the prepared merge sat in a tier. The state file now carries an absolute `store` field and the continuation *finds* the prepared merge by walking the stores — refusing outright, rather than guessing, if two are prepared at once (a gate yields on the first divergence and stops, so two means the state is not what any continuation assumes). The merger sub-agent reads `store` too: `changed_files` are relative to it, and it was previously free to assume memory. Two incidental corrections fell out. The tier's local-`live` failure path gained memory's parenthesized-reason discriminator, so a ref lock is no longer sent into a merge that cannot help it. And `resolve.sh`'s two memory repairs — creating a missing remote, pushing a missing `live` — stopped `exit 0`-ing: a repair to memory says nothing about the tiers, and returning there left a diverged tier undetected, which is exactly how the standalone resolver silently passed a broken store. 16 cases in `tests/tier_divergence.bats`.
