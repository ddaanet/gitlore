## What the item text got wrong against the tree

- **"The node is 340 lines, so the addition stays under the 400-line cap."** It
  does not, for two decisions. D50 alone consumes the entire remaining budget,
  and it only does so after four rounds of compression (a one-line title, three
  density passes). See the deviation above.
- **`git-hooks-and-entry-points.md` now sits at exactly 400/400.** That is the
  state a cap stops signalling from — the next line added anywhere in the node
  blocks the build, and will read as a tooling failure rather than as "this node
  is due to be split". The outline already argues this for `docs/design.md`; it
  is now true of this node too, and the split is a decision for my human
  partner, not something to absorb by trimming argument. Item 4.3 touches the
  changelog rather than this node, so nothing is blocked today.
- **The two `## Mechanism` enumerations were already stale** before this item —
  both list `gitlore_sync_memory_to_live`'s steps and neither had the pin guard,
  which landed in Item 1.2. Fixed here; the item text did not anticipate it.
- **Only one relay comment block in `scripts/lib/index-sync.sh` carries the
  measurement citation**, not several — the item says "comment blocks", plural.
  `gitlore_relay_write` and `gitlore_relay_drain` describe the confinement's
  consequences but never cite the measurement, so there was nothing to back-fill
  in them and adding a second citation would be noise.
- **Both Item 1.3 invariants verified against the scripts**, not the hub:
  up-before-stage from `gitlore_adopt_recovered_merge` in
  `scripts/lib/resolve.sh` (it composes up, stages `MEMORY.md` and the tier
  together, and stages nothing when the up projection fails), and the
  no-wrapper-remedy rule from the pin abort in `gitlore_sync_memory_to_live` in
  the same file. The restamp asymmetry was checked at the same time and is
  stated accordingly: the write-failure and unknown-status aborts `touch` the
  commit-msg file, the pin abort does not, because it writes nothing.
