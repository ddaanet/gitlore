## Remaining

- A `PostToolBatch` hook that exits non-zero is recorded by Claude Code as `hook_stopped_continuation` and ends the turn with the synthetic reply "No response requested.", so the agent says nothing and the user sees an empty turn. `scripts/cc-hooks/index-sync-post.sh` reaches that state when its pre-image stash vanishes between the `[ -f "$stashfile" ]` check and the `awk` read in `gitlore_index_pairs`: `cmp -s` on a missing file returns non-zero and falls through to the propagation path under `set -e`. Seen only when two copies of the hook ran at once, which the eval harness no longer does, but any other death of a `PostToolBatch` hook has the same silent effect. Decide whether the batch hooks should degrade to a reported skip instead of dying, and audit the six `PostToolBatch` scripts in `hooks/hooks.json` for other fatal paths.
- `tests/evals/README.md` describes how the eval repo's hooks are wired and does not say the runner bypasses the dogfood shim; add that, as prose, to Sonnet.
- `plans/macos-check/out/` is untracked and belongs to no task in this frame; decide whether it is kept, ignored or removed.
