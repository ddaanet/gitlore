## Open decisions

- Whether "index one-liner canonical" (D17's core premise) survives its authoring cost: the case for it rests only on retrieval evidence (always-loaded, 100% vs 75%), never on authoring, and live dogfooding suggests it causes extra tool calls and thinking — the agent writes a considered `description:` as part of the file, then the index line, and the sync silently replaces the richer text with the terser hook (twice this session, seen only via a system-reminder). Reconcile applies this rule at scale over ~40 stale-index files, so settle it first. Reframings unexplored: frontmatter authoritative at authoring + index derived at commit; or keep canonical-index but make the hook report what it replaced.
- Where the memory-commit magic file lives. Decided in principle: move to `.claude/gitlore-memory-message` (name leaves room for nested repos, `.claude/gitlore-memory-ddaa-message/`), needs a `.gitignore` entry. Load-bearing, not cosmetic — the gitdir path is unwritable by the agent under auto mode via *any* tool (heredoc → audit-tampering; Write → bypass), so the intended one-call handoff cannot execute at all. Motive is that Write has no sandbox to disable, and a flag you must remember on one specific Bash command is a defect, not a workflow. Open: whether `pre-commit` should also print the direction on a plain run, so the message is written in the same turn as the commit.
- Whether a net-new index line propagating is intended D17 behavior or scope creep: the slice-1 plan lists net-new-line seeding as out of scope, but an absent pre-image entry reads as "changed", so a brand-new index line does overwrite an existing `description:`. Only a file with no `description:` line at all is genuinely unseeded, since the setter matches `^description:`.
- Whether `systemMessage` should show the before/after text or just name the file — the silent discarding of authored prose is the failure mode motivating the task, and it bears on the canonical-index question above. Note `additionalContext` does not inject under `--print`, which constrains how that half can be tested.
